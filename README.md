# bare

A minimalist, text-only Android launcher that treats the phone as a tool: take it out, communicate, put it away.

- Black screen, monospace text, a single amber accent for things that need you.
- Notifications become a large, ordered list on the home screen; group chats are summarized, important messages re-alert.
- Habit apps ask for a reason when there's nothing new waiting.
- Instagram (DMs only) and YouTube (search + subscriptions, no Shorts or feed) run as restricted micro-apps.
- System-wide DNS filter for distracting sites.

Local and private: no accounts, no analytics, no telemetry.

Full specification (Spanish): [`docs/SPEC.md`](docs/SPEC.md).
